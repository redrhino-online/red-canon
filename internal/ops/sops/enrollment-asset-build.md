# Enrollment asset build SOP

This procedure builds the sales asset. It covers gather inputs, write the
script, set checkpoints, write objections, practice, and review.

## Trigger

A client buys the enrollment service. The enrollment specialist starts this
procedure in the Launch stage.

## Roles

- Enrollment specialist: owns the asset and writes the script.
- Delivery lead: gives the client's one currency and roadmap.
- Client and team: practice the script and give feedback.

## Procedure

1. Gather the inputs. Get the one currency, the roadmap, and the price.
2. Study the buyer. List the top pains, goals, and fears.
3. Write the script. Follow the call shape: frame, diagnose, invite.
4. Write the questions. Ask for exact current numbers and goal numbers.
5. Set the checkpoints. Use intent, commitment, value, confidence, and desire.
6. Write the objections. List the common doubts and a question for each one.
7. Build the card. Put the checkpoints on one page.
8. Practice the script. Run role play with the client and their team.
9. Review the calls. Listen to recorded calls and note where each call ended.
10. Fix the asset. Update the script and the card from what you learn.

Keep the script tied to the product roadmap. Do not invent a new offer.

## Decision points

- If the one currency is missing, stop. Get it before you write.
- If a checkpoint fails on most calls, fix the script, not the lead.
- If the client wants pressure, say no. Keep the call honest.
- If the team cannot run the script, practice again before launch.

## Escalation

Tell the delivery lead when the inputs are missing or the client wants a
pushy script. If the client is not ready, tell the operations owner.

## Records

Save the script, the question set, the checkpoint card, and the objection sheet
in the client folder. Keep the call notes and the review notes with them.
