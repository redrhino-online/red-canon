# Role-play practice SOP

This procedure drills the team on the enrollment call. It covers set the scene,
run the call, score, coach, and repeat.

## Trigger

The enrollment asset is ready, or the team needs practice. The enrollment
specialist runs this procedure before live calls.

## Roles

- Enrollment specialist: runs the drill and scores the calls.
- Seller: plays the caller and runs the script.
- Partner: plays the lead and gives the doubts.

## Procedure

1. Set the scene. Pick one lead type and one doubt to work on.
2. Set the goal. Name the one skill the seller must show.
3. Run the call. Let the seller run the script from start to end.
4. Play the lead. Raise real doubts. Do not make it easy.
5. Score the call. Use the checkpoint card. Mark each gate pass or fail.
6. Coach on one thing. Give one clear fix. Show the better words.
7. Run it again. Repeat the same scene with the fix.
8. Swap roles. Let the seller play the lead to feel the other side.
9. Note the pattern. Write down the doubt that keeps coming up.
10. Repeat. Drill until the seller passes the gates with no pressure.

Drill one scene at a time. Do not drill the whole call at once.

```mermaid
flowchart LR
    A[Scene] --> B[Call] --> C[Score] --> D[Coach]
```

## Decision points

- If the seller fails a gate, stop and coach. Do not run the whole call again.
- If the lead is too easy, make the doubt harder.
- If the seller feels stuck, slow down and drill one gate.
- If the team keeps missing one doubt, update the objection sheet.

## Escalation

Tell the delivery lead when a seller cannot pass the gates after many drills.
If the team is not ready, tell the operations owner before live calls.

## Records

Save the drill notes, the scores, and the doubt list in the team folder. Keep
the date and the seller name with the scores.
