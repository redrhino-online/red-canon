# Client onboarding SOP

This procedure starts a new client well. It covers the welcome, the goals, the
start date, access, the plan, and the first module.

## Trigger

A client signs the agreement and pays the first invoice. The delivery lead
starts this procedure within two business days.

## Roles

- Delivery lead: owns the whole procedure and the client relationship.
- Coach: joins the kickoff and leads the first module.
- Enrollment specialist: hands over the client notes and the sales context.

## Procedure

1. Send the welcome note. Thank the client. Name the delivery lead and the
   coach. Give the start date.
2. Book the kickoff call. Put it on the calendar within five business days.
3. Collect the client's goals. Ask for the numbers they want to hit. Ask for
   the date they want to hit them.
4. Set the success goals. Write one goal for the program. Make it specific and
   measurable.
5. Set the start date. Pick the first day of the program. Tell the client.
6. Set up access. Give the client their login. Give them the call links and the
   file folder.
7. Build the one-page plan. Put the goals, the dates, and the modules on one
   page.
8. Assign the first module. Tell the client what to do before the first call.
9. Run the kickoff. Walk through the plan. Answer questions. Confirm the start
   date.
10. Save the notes. Put the plan and the goals in the client folder.

The steps run in order. Do not skip the goals step.

```mermaid
flowchart LR
    A[Welcome] --> B[Goals] --> C[Plan] --> D[Kickoff]
```

## Decision points

- If the client has no clear goal, pause and help them set one. Do not start
  the program without a goal.
- If the client cannot start on the planned date, move the date. Tell the coach.
- If the client needs extra access, ask the delivery lead to approve it.
- If the client is not ready, keep them in pre-sell. Do not force the start.

## Escalation

Tell the delivery lead when a goal is missing, a date slips, or the client is
upset. If the delivery lead cannot fix it, tell the operations owner.

## Records

Save the welcome note, the goals, the one-page plan, and the kickoff notes in
the client folder. Keep the start date and the access list in the same place.
