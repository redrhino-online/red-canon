# Swipe card catalog

This catalog helps you find cards about the same product or idea. It does not
move or change any exported card.

The arrows show how the catalog points back to the source cards.

```mermaid
flowchart LR
    A[Source lists] --> B[Product groups] --> C[Original cards]
```

## Confirmed title matches

These groups use the same product name in their card titles. This confirms a
product match, not that the cards were part of one campaign. Each table keeps
the matching source cards together; qualifying local images link to their
original files. A source card without an image in its table has no qualifying
local image.
