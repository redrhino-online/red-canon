# Plan playbook

This playbook sets the numbers and the plan for the whole build.

## Goal

Agree on the numbers and the plan. Good looks like one page. It has clear goals
for revenue and clients. It has the key numbers: cost per lead, cost per
session, cost per client, and the value of a client.

## When to use

Use this at the start of the build. It is Station 0. Use it before any market
work.

## Roles

- Delivery lead: runs the session and owns the plan.
- Coach: helps the client set real goals.
- Client: gives the real numbers.

## Inputs

- The client's current revenue and client count.
- The client's costs.
- The client's goals for the next 12 months.

## Steps

1. List the client's current numbers.
2. Set a revenue goal for the year.
3. Set a client goal for the year.
4. Work out the value of one client.
5. Work out the cost per lead, per session, and per client.
6. Write the plan on one page.
7. Set a date to review the plan every 90 days.

The plan turns goals into numbers.

```mermaid
flowchart LR
    A[Goals] --> B[Numbers] --> C[One-page plan] --> D[90-day review]
```

## Gate

The plan is specific and measurable. It gets reviewed on a schedule. If a number
is missing, stop and find it.

## Metrics

- Client value.
- Cost per lead.
- Cost per session.
- Cost per client.

## Outputs

- A one-page plan with clear numbers.

## Common failures

- The plan is vague. Fix: use real numbers, not guesses.
- No review date. Fix: book the 90-day review now.
- The goals are too big to track. Fix: set one clear goal per number.
