# Plan playbook

This playbook sets the numbers and the plan for the whole build.

## Goal

Agree on the numbers and the plan. Good looks like one page. It has clear goals
for revenue and clients. It has the key numbers: cost per lead, cost per
session, cost per client, and the value of a client. The plan names one master
number: the lifetime value of a client.

## When to use

Use this at the start of the build. It is Station 0. Use it before any market
work.

## Roles

- Delivery lead: runs the session and owns the plan.
- Coach: helps the client set real goals.
- Client: gives the real numbers.

## Inputs

- The client's current revenue and client count.
- The client's costs.
- The client's goals for the next 12 months.

## Key ideas

- **The lifetime value rule.** Lifetime value is the one number that bakes in
  every other number. If it goes up, every ad, call, and email is more
  forgiving.
- **The one-page plan.** One page. Nine numbers. Reviewed every 90 days.
- **The swim lanes.** Five lanes each lift the same funnel: pages, messages,
  ads, outreach, and reps. You do not need all five. You need the right one.

## Steps

1. List the client's current numbers.
2. Set a revenue goal for the year.
3. Set a client goal for the year.
4. Work out the value of one client over one year.
5. Work out the cost per lead, per session, and per client.
6. Write the plan on one page.
7. Set a date to review the plan every 90 days.
8. Name the one lane to fix first.

The plan turns goals into numbers.

```mermaid
flowchart LR
    A[Goals] --> B[Numbers] --> C[One-page plan] --> D[90-day review]
```

## The numbers that matter

Use these as targets, not promises. They are examples from the canon.

- **The 1% rule.** Plan for about 1 lead in 100 to buy. If it works at 1%, it
  works at any higher rate.
- **Lead value.** A high-ticket lead is worth about the price divided by 100.
- **A $3,000 floor.** A premium offer starts at $3,000. Below that, the ad
  math is hard.
- **The lead grows with age.** A lead is worth little on day one and a lot by
  month three. Follow-up is where the money is.

```mermaid
flowchart LR
    A[Day 1] --> B[Month 2] --> C[Month 3]
```

## Gate

The plan is specific and measurable. It gets reviewed on a schedule. If a number
is missing, stop and find it.

## Metrics

- Client value and lifetime value.
- Cost per lead.
- Cost per session.
- Cost per client.

## Outputs

- A one-page plan with clear numbers.
- The one lane to fix first.

## Common failures

- The plan is vague. Fix: use real numbers, not guesses.
- No review date. Fix: book the 90-day review now.
- The goals are too big to track. Fix: set one clear goal per number.
- Chasing cheap leads. Fix: raise the lifetime value first.
