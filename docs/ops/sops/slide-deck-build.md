# Slide deck build SOP

This procedure turns a content crusher into a module slide deck.

## Trigger

The content crushers are filled. The producer starts this procedure in the
Delivery station.

## Roles

- Producer: builds the deck.
- Delivery lead: owns the template.
- Coach: checks the slides against the script.
- Client: approves the deck.

## Procedure

1. Open the [slide template](../checklists/slide-template.md).
2. Add the title and the promise slide.
3. Add one emotional image per slide.
4. Keep text short. No long bullet lists.
5. Add the three how-to action slides.
6. Add the example or proof slide.
7. Add the deliverable slide.
8. Add the action slide.
9. Apply the brand colors and fonts.
10. Give credit for any borrowed image.
11. Check the slides match the script.
12. Export the deck.

One template repeats across every step.

```mermaid
flowchart LR
    A[Crusher] --> B[Template] --> C[Brand] --> D[Deck]
```

## Decision points

- If a slide has two ideas, split it.
- If an image is off brand, replace it.
- If the deck does not match the script, fix the deck.
- If a borrowed image has no credit, add it.

## Escalation

Tell the delivery lead when the brand assets are missing. Tell the coach when
the deck leaves the offer.

## Records

Save the deck and the template in the client folder. Keep a build guide with
them.
