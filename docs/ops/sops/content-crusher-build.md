# Content crusher build SOP

This procedure fills one content crusher for one step of the offer.

## Trigger

The product roadmap is approved. The producer starts this procedure in the
Content station.

## Roles

- Producer: fills the crusher.
- Delivery lead: picks the step.
- Coach: checks the offer fit.
- Client: approves the sheet.

## Procedure

1. Pick one step of the roadmap.
2. Write the topic and title.
3. Write the promise with a metric and a timeline.
4. Name the top three frustrations.
5. Write the goal the buyer wants.
6. Pick one image or metaphor.
7. Name the deliverable for the step.
8. Write the three how-to actions.
9. Add one example or proof.
10. Write one decision point.
11. Write one action for the buyer.
12. Check the sheet lives inside the offer.

The sheet turns one step into slides.

```mermaid
flowchart LR
    A[Step] --> B[Fields] --> C[Deliverable] --> D[Slides]
```

## Decision points

- If there is no deliverable, design one before slides.
- If the promise has no metric or timeline, fix it.
- If the sheet leaves the offer, cut the part that does not fit.
- If it is too long, move detail to the call.

## Escalation

Tell the delivery lead when a step is too thin to teach. Tell the coach when
the crusher does not match the offer.

## Records

Save each crusher in the client folder, one file per step. Keep them in step
order.
