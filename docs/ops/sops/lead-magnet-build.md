# Lead magnet build SOP

This procedure builds one lead magnet from one step of the offer.

## Trigger

The funnel is being built. The producer starts this procedure in the Funnel
station.

## Roles

- Producer: builds the cheat sheet and the PDF.
- Delivery lead: picks the step.
- Coach: checks the offer fit.
- Client: approves the asset.

## Procedure

1. Pick one hot step of the signature solution.
2. Name the magnet for the person and the result.
3. Write the one-page cheat sheet.
4. Keep it to about ten minutes of use.
5. Leave one step for the call.
6. Build the short PDF: title, proof, bio, problem, steps, and action.
7. Use a picture of the thing itself.
8. Add a second click before the page.
9. Set the PDF to send by email.
10. Pair the magnet with the authority video.
11. Test two titles and keep the winner.

The magnet is one page that pairs with the video.

```mermaid
flowchart LR
    A[One step] --> B[One page] --> C[Email] --> D[Video]
```

## Decision points

- If the magnet is long, cut it to one page.
- If it gives the full answer, remove the last step.
- If it is a quiz or an ebook, rebuild it as a cheat sheet.
- If opt-in is low, test a new title first.

## Escalation

Tell the delivery lead if no step makes a good magnet. Tell the coach if the
magnet does not match the offer.

## Records

Save the cheat sheet, the PDF, and the test results in the client folder.
