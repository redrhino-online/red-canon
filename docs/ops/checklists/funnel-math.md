# Funnel math checklist

Run this list to work out the numbers for one funnel.

Each step has one number.

```mermaid
flowchart LR
    A[Spend] --> B[Leads] --> C[Calls] --> D[Clients]
```

## Before you start
- [ ] Get the offer price.
- [ ] Get the current cost per lead and show rate.
- [ ] Read the [numbers playbook](../playbooks/numbers.md).

## Steps
- [ ] Write the offer price.
- [ ] Work out the value of one lead: price divided by 100.
- [ ] Write the cost per lead.
- [ ] Write the leads that book a call.
- [ ] Write the calls that enroll.
- [ ] Work out the cost per booked call.
- [ ] Work out the cost per client.
- [ ] Work out the lifetime value of a client.
- [ ] Compare the cost per client to the lifetime value.
- [ ] Find the weakest step in the chain.
- [ ] Change one number and watch the chain move.

## Done when
- [ ] Every step has a number.
- [ ] The cost per client is lower than the lifetime value.
- [ ] The weakest step is named.
