# Renewal and win-back checklist

Run this list near the end of a client term, or when a client goes quiet.

The path has four steps.

```mermaid
flowchart LR
    A[Health check] --> B[Next step] --> C[Offer] --> D[Win-back]
```

## Before you start
- [ ] Pull the [client scorecard](client-scorecard.md).
- [ ] List the results so far.
- [ ] Know the next offer to present.
- [ ] Pick a good time to talk.

## Steps
- [ ] Check the client's health: results, use, and mood.
- [ ] Ask how the work is going.
- [ ] Show the results in plain numbers.
- [ ] Name the next step that fits their goal.
- [ ] Make the offer with no pressure.
- [ ] Listen to any doubt.
- [ ] If they are quiet, send a short win-back note.
- [ ] Set a date for the next check-in.

## Done when
- [ ] The client has a clear next step.
- [ ] The offer is made or the win-back is sent.
- [ ] The next check-in is on the calendar.
